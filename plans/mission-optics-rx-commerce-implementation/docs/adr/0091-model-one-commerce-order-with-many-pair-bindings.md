# Model One Commerce Order With Many Pair Bindings

Mission stores one canonical Commerce Order for each external order reference within a Store Connection. That order may own many pair-level Order Package Bindings, and each binding connects one Cart Execution Plan and its commerce lines and financial allocations to one Fulfillment Case. This preserves Shopify's order-level authority while allowing each prescription pair to progress, hold, change, ship, cancel, or remake independently.
