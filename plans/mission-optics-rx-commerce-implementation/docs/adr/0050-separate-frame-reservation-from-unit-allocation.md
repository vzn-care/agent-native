# Separate Frame Reservation From Frame Unit Allocation

After Mission accepts a paid order from an authoritative Commerce Snapshot, it creates a SKU-level Frame Reservation so sellable inventory is not oversold while prescription and measurement work continues. Mission assigns and inspects a specific Frame Unit only at Production Release, when the reservation becomes a Frame Allocation. Reservation deadlines are merchant-configurable within Mission bounds. Expiration never silently releases stock from a paid obligation: it creates a customer-safe decision requiring an explicit extension, compatible substitution, backorder treatment, or cancellation through the order-owning channel. A frame change transfers the reservation only after optical validation, repricing, and inventory confirmation succeed.
