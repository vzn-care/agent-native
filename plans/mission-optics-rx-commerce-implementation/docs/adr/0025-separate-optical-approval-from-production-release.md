# Separate Optical Approval from Production Release

An Optical Reviewer provides Optical Approval for the current prescription, measurements, frame, lens, and manufacturing interpretation, while a different Release Operator grants Production Release after confirming Financial Clearance, quote integrity, Frame Allocation, approvals, and holds against the same revisions. Future automation may replace standard operational release, but manual exceptions retain separation and break-glass release requires a reason and retrospective second review.
