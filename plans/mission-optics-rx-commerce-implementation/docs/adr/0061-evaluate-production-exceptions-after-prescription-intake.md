# Evaluate Production Exceptions After Prescription Intake

Production exceptions are post-intake operational decisions, not promises made during pre-configuration. When a paid pair's verified prescription falls outside its Published Eligibility Envelope, an authorized Rx Exception Manager reviews the actual prescription, frame, lens, measurements, lab routing, and pair-specific production facts. The manager either initiates a compatible Configuration Rebase or Change Proposal, or grants a case-specific Production Exception Approval when the configuration remains within an already documented Verified Production Capability. If that broader capability is not documented, Mission must first obtain technical or lab confirmation and publish a new capability revision. One exception does not expand the customer-facing envelope.
