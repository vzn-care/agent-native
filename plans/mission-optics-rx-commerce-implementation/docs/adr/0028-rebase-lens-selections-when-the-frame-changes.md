# Rebase Lens Selections When the Frame Changes

Only a commercially complete, quoted Rx Configuration may enter the cart, but changing the frame does not force the shopper to reselect lenses. A Configuration Rebase applies the existing lens choices to the candidate frame and evaluates compatibility and pricing: a compatible frame creates a new accepted revision and Rx Quote, while an incompatible frame leaves the current configuration unchanged and returns specific blocking reasons and corrective options.
