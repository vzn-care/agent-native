# Support Traceable Estimated Fitting Heights

Merchants may offer progressive pathways that use an Estimated Fitting Height instead of direct fitting-height measurement, but the estimate must use documented frame geometry, lens-design data, and at least one subject-specific wearing-position input. The resulting Measurement Record preserves the value, method and model version, inputs, confidence, merchant policy, Optical Approval, and later adaptation or remake outcome; the system never represents an estimate as a direct measurement.
