# Use Shopify Order Edit and Additional Payment Collection

For an accepted higher-price Change Proposal in the HyperLight pilot, the Shopify adapter edits the affected unfulfilled lens or service components, commits the calculated order edit, and sends the purchaser Shopify's additional-payment collection URL or order invoice. Mission re-fetches the order and withholds Financial Clearance and Production Release until the exact pair package and full additional payment are authoritative. Each adjustment is idempotent and binds the expected order revision, lines, amount, currency, and purchaser acceptance. If the order cannot be edited or Shopify cannot provide a safe collection path, the adapter leaves the order unchanged and uses merchant-authorized cancellation and refund followed by a replacement checkout.
