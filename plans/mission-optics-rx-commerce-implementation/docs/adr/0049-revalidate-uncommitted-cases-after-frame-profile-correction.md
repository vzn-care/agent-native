# Revalidate Uncommitted Cases After a Frame Profile Correction

A Frame Profile Correction creates a new approved Frame Optical Profile revision rather than changing the prior revision in place. New configurations use the corrected revision, and every dependent case that has not reached Production Commitment is automatically revalidated against it. A case with an incompatible or materially changed result is quarantined, its dependent approvals are invalidated, and the merchant receives a customer-safe action or status notification. Production-Committed and completed Production Attempts retain the exact profile revision originally used. If a correction reveals a safety or quality risk in committed or completed work, Mission opens an incident or recall workflow instead of rewriting history.
