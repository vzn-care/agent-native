# Allow Controlled Exceptions Within Verified Production Capability

Mission distinguishes the conservative customer-facing Published Eligibility Envelope from the broader, independently validated Verified Production Capability of a particular frame, lens, lab, and process combination. An Rx Exception Manager explicitly granted the capability through Access Policy may issue a case-specific Production Exception Approval beyond the published envelope only after the actual prescription and pair-specific facts are available and only when the exact configuration remains within verified capability. The approval records the approver, reason, supporting technical or lab evidence, exact dependent revisions, time, and outcome, and expires with that case. It does not expand the catalog or create a standing precedent. No role may override an unverified or hard safety and manufacturing boundary.
