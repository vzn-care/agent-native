# Publish Versioned Merchant Program Configurations

Each merchant operates through a Merchant Program Configuration containing its lens offering, price book, promotion rules, deadlines, communication settings, Delivery Policy, and permitted automated approvals. Changes begin as drafts, pass automated sandbox validation, and become immutable effective versions when published, optionally on a future schedule. Mission approval is required for optical, production, access, and safety-sensitive changes; merchants may independently publish permitted branding and commercial changes. Existing configurations, quotes, orders, and Production Attempts remain pinned to their original version unless explicitly re-evaluated. Rollback prospectively republishes a known-good version and never rewrites history.
