# Send Immutable Acknowledged Production Instructions

Mission releases manufacturing through an immutable Production Instruction Package bound to one Production Attempt and the exact approved configuration, prescription, measurement, Frame Optical Profile, Production Shape, lens, quote, and authorization revisions. Every package has a content digest and idempotency key, and the lab must explicitly accept or reject it. Mission never edits an accepted package in place. Before Production Commitment, a correction requires acknowledged revocation of the prior package and release of a new package revision. After Production Commitment, corrective work creates a new Production Attempt, remake, or incident workflow. Mission preserves both Mission and lab timestamps, with the lab's explicit Production Commitment acknowledgment governing the manufacturing cutoff.
