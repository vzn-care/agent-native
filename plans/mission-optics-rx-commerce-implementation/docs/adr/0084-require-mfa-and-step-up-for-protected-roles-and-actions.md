# Require MFA and Step-Up for Protected Roles and Actions

Every Mission workforce user and every merchant owner or administrator must use multifactor authentication. Fresh Step-Up Authentication is required for System Administrator publication, protected-data export, role or access-policy changes, Production Release, QA exceptions, and other designated high-consequence actions. Ordinary shoppers may use verified email-based access without permanent MFA, but must complete one-time identity verification when claiming a Prescription Subject, authorizing prescription reuse, changing protected contact information, or performing another sensitive record action. High-consequence agent actions require explicit human approval in addition to authentication and role authorization.
