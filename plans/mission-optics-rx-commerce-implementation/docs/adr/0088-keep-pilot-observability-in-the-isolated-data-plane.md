# Keep Pilot Observability in the Isolated Data Plane

The HyperLight pilot uses Agent Native's in-database observability and audit surfaces in the isolated Neon environment. Prompt content, action arguments and results, prescription data, documents, customer text, and commerce payloads are redacted by default. Operational telemetry records only opaque IDs, event and transition names, reason codes, durations, counts, and sanitized errors; security audit evidence remains distinct from performance telemetry. No trace or product-analytics export to an external provider is allowed until the exact service, configuration, BAA status, fields, and retention pass review. Automated leak tests inject protected-looking values and fail the launch gate if they appear in logs, traces, analytics, alerts, or error reports.
